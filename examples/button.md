# Button

## Purpose
Triggers a clearly labeled, immediate action.

## Variants
- primary
- secondary
- destructive

## Sizes
- compact
- standard
- large

## Tokens
- `color.accent.primary`
- `color.text.primary`
- `radius.control`
- `spacing.md`

## States
- default
- hover
- active
- focus
- disabled
- loading
- error

## Behavior
Use a native button for actions. Preserve the label and layout while loading.

## Accessibility
Use a visible focus indicator, accessible name, keyboard activation, and disabled semantics.

## Responsive
Keep the target usable at narrow widths; allow intentional full-width actions in compact forms.

## Use when
The user needs to trigger an action.

## Avoid when
The destination is a page or resource; use a link instead.

- Icon Button
